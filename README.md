# Idea Collection

A modern React Native (Expo) app for capturing ideas the moment they strike — by voice, by text, or as a melody you play on a built-in piano.

## Features

| # | Feature | How it works |
|---|---------|--------------|
| 1 | **Record ideas live** | Big pulsating record button on the *Record* tab (`expo-audio`, high-quality m4a saved to app documents). Live timer + audio-bars visualization. |
| 2 | **Filter by tags** | Add tags to any idea; the *Ideas* tab shows all tags as tappable chips (multi-select) plus full-text search across title, notes, tags and category. |
| 3 | **Categories** | Every idea gets a color-coded category (Spark, Work, Personal, Music, Someday — plus your own, created inline). Filter the feed by category. |
| 4 | **Reminders** | Attach a reminder with quick presets ("In 1 hour", "Tonight", "Tomorrow 9 AM") or a custom date/time picker. Scheduled as a local notification (`expo-notifications`); tapping the notification deep-links into the idea. |
| 5 | **Google / iOS calendar** | One tap adds the idea to any writable device calendar (`expo-calendar`). Google-account calendars are detected and badged. Uses the native "add event" form so you can tweak before saving. |
| 6 | **Musical ideas** | Any idea can be a melody instead of words. |
| 7 | **Playable piano** | The *Melody* tab is a note composer: pick a letter (♯/♭), octave and duration (1/1 – 1/16) and notes are written onto a real 5-line staff as musical symbols. One tap plays the whole score back using bundled piano samples — the piano is the sound, notes are the input. |
| + | **Text ideas** | The *Write* tab is a dedicated screen for typing ideas — title, notes, tags, category and reminder, no microphone needed. |
| + | **Light & Dark Modern themes** | Moon icon in the *Ideas* header: pick **Dark Modern**, **Light Modern**, or follow the system. Preference is remembered. |

## Stack

- **Expo SDK 58** · React Native 0.88 · TypeScript (strict) · Expo Router (file-based navigation)
- **expo-audio** — live recording + playback (voice ideas and piano samples)
- **expo-notifications** — reminder scheduling with deep-link back into the app
- **expo-calendar** — device/Google calendar integration via the system event form
- **zustand + AsyncStorage** — persistent local idea store
- 24 synthesized piano WAV samples (2 octaves), generated by [`scripts/generate-piano-notes.mjs`](scripts/generate-piano-notes.mjs)

## Project layout

```
src/
  app/            # Expo Router screens
    (tabs)/       # Ideas · Record (voice) · Write (text) · Piano
    idea/[id].tsx # Idea detail: playback, reminder, calendar, edit
  components/     # Idea card, piano keyboard, meta form, reminder picker…
  lib/            # store, notifications, calendar, piano engine, theme, types
assets/notes/     # generated piano samples (wav)
scripts/          # piano sample generator
```

## Getting started

```bash
npm install
npx expo start          # press a (Android) or i (iOS)
```

- Voice recording, piano playback, tags, categories and search all work in **Expo Go**.
- **Calendar integration requires a development build** (`expo-calendar` is not available in Expo Go):

```bash
npx expo run:android    # or: npx expo run:ios
```

- Reminders: local notifications work on device; grant the notification permission when asked.
- Regenerate piano samples any time: `npm run notes:generate`.
